# Portafolio de Victor Alejandro Gallegos

Sitio personal para presentar trabajo de producto digital, prototipado, automatización con IA y exploración visual.

## Estado

La base del sitio está preparada. Las evidencias de los proyectos se añadirán en una fase posterior:

- MOGI
- Herramienta de ejercicios visuales
- Prototipos de ajedrez y videojuegos
- Laboratorio de 3D y diseño visual

## Estructura

```text
Portafolio/
├── index.html
├── styles.css
├── script.js
├── assets/       # Imágenes, CV y recursos públicos
├── projects/     # Casos de estudio y evidencias de proyectos
└── .github/
    └── workflows/
        └── pages.yml
```

## Publicación

El sitio está pensado para GitHub Pages. El workflow de Pages publica el contenido de la raíz del repositorio cuando se hace push a `main`.

## Regla de privacidad

No subir secretos, tokens, bases de datos, datos de clientes ni código privado de MOGI. Los casos de estudio deben mostrar únicamente información pública, capturas seleccionadas y una explicación verificable del trabajo.
